# #132 파노라마 카드 회귀 검사

```sh
bash Tools/PanoramaLayout/run.sh
```

실제 `TripHistoryCard`와 `VisitedPlaceCardView`를 macOS SwiftUI ImageRenderer로 그립니다.
네트워크 이미지 공급자·모델·폰트·햅틱만 테스트 대역이며 API 요청이나 사용자 저장소 접근은 없습니다.

- 12:1, 2.2:1, 4:3, 3:4, 1:1 합성 사진
- 카드 폭 280/334/390에서 원본 비율로 인한 폭 확장 방지
- 카드 양옆 여백의 픽셀 검사로 이미지 넘침 방지
- 히스토리 카드 높이 190 유지

이미지 디코딩, 캐시 품질, iPhone 렌더링 자체를 검증하는 테스트는 아닙니다.
실기기에서는 국문 관광정보 API의 회룡포·경희궁 흥화문·환호공원 사진으로 다음을 확인합니다.

1. 16번 방문 확인 화면에서 사진과 하단 정보 영역의 좌우 폭이 같은지
2. 카드 모서리와 스와이프·방문 선택·흑백 표시가 유지되는지
3. 히스토리 목록에서 사진이 카드 밖으로 나오지 않고 제목·날짜가 보이는지
4. 일반 가로/세로 사진도 왜곡 없이 중앙 크롭되는지

고정 크기 썸네일은 기존처럼 aspect-fill 방식으로 일부가 잘립니다. 원본 데이터·URL·저장 구조는 수정하지 않습니다.
