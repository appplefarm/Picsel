# 사진 탐색 연결 스냅 프로토타입 (#131)

`bash Tools/PhotoSnapNavigation/run.sh`로 실제 모델·카메라·선택 정책·ViewModel을 검사합니다.
외부 API, 이미지 다운로드, SwiftData 저장소 또는 RealityKit 렌더러는 실행하지 않습니다.

- 배치 번호(사진 ID와 별개): 1부터 시작하는 기존 `SpatialPlacePlacement` 순서.
- 준비 완료 → 로딩 페이드아웃 대기 0.35초 → 초기 카메라에서 4초 동안 깊이 0.80만큼 확대. 초반 가속 없이 거의 등속으로 접근하고 끝에서 부드럽게 감속.
- 초기 이동에서는 사진을 선택하지 않으며 가로·세로 위치도 유지. 가장 가까운 사진의 초점/마그넷 깊이 밖에서 멈춤.
- 주변 양방향 고리: 2 ↔ 7 ↔ 3 ↔ 4 ↔ 6 ↔ 5 ↔ 2. 1번은 모든 사진과 연결.
- 자동 순회가 아닌 사용자 드래그 기반. 사진을 미는 방향 반대편의 연결된 사진으로 한 번에 한 칸 스냅.
- 직접 탭은 거리·연결 고리 제한 없이 해당 사진에 포커스. 같은 사진을 다시 탭하면 상세 화면 표시.
- 짧거나 이웃을 향하지 않은 드래그는 현재 사진으로 복귀. 깊이는 이동 대상에 맞게 자동 조정.
- 일부 사진 로딩 실패 시 해당 번호를 유지한 채 건너뜀. 1번이 없어도 초기 화면은 미선택 상태로 소폭 확대.
- 핀치로 줌아웃하면 연결 스냅을 벗어나 기존 자유 탐색. 다시 사진에 마그넷/탭 포커스하면 연결 스냅 재개.
- 초기 줌인은 한 번만 실행하고, 먼저 드래그/탭/초기화를 하면 예약된 자동 이동을 생략.
- Reduce Motion에서는 긴 초기 이동/관성 없이 동일한 미초점 깊이로 이동.

사진 배치 좌표는 수정하지 않았습니다. 초기에는 자유 탐색 상태이며 사용자가 사진에 포커스를 맞춘 뒤 연결 스냅을 시작합니다.
1번은 모든 사진의 공통 연결점으로 유지합니다. 초기 확대 시간/거리는 `PhotoInteractionSettings`에서 조정합니다.
방향 판정과 이동 감각은 실기기 피드백을 바탕으로 추가 조정할 수 있습니다.

## 프리뷰 / 실기기 확인

- 기존 `Spatial Photo Canvas` Preview: 4초 동안 확대하되 특정 사진이 선택되거나 선명해지지 않는지, 초반 가속 없이 시작해 끝에서 부드럽게 멈추는지 확인.
- 사진을 선택한 뒤 같은 사진 탭 → 상세. 뒤로 돌아와도 초기 줌인이 다시 실행되지 않는지 확인.
- 초기 줌인 도중 드래그, 빠른 연속 스와이프, 탭과 드래그의 충돌 확인.
- 1번에서 각 사진 이동, 양방향 고리, 작은 드래그 원위치 복귀 확인.
- 핀치와 드래그 동시 입력, 화면 맞춤, 작은 화면 및 Reduce Motion 확인.

정책 검사는 카메라 목표값을 확인합니다. RealityKit의 실제 애니메이션·햅틱·터치감은 실기기 검증이 별도로 필요합니다.
