### 발견한 품질 문제: 부산 남구 코드 중복

`26290 / 부산광역시 남구`가 63번·76번 도형에 중복되어 있고 `27200 / 대구광역시 남구`는 없다.

- 63번 경계 범위 (EPSG:5186): `(388000.959, 278470.444) – (394085.633, 287095.281)`
- 76번 경계 범위 (EPSG:5186): `(340551.441, 357823.962) – (345336.269, 363653.789)`
- 76번은 대구 남구 위치로 추정된다. 기존 경계와의 공간 대조가 필요하다.
- 제공 페이지의 2026-07-10 문의에도 같은 문제가 보고되어 있고 7월 14일 수정 업로드 답변이 있다. 그러나 이번에 받은 원본에서는 중복이 재확인된다.
- **중복을 임의 삭제하거나 같은 지역으로 합치지 않는다.** 검증 실패 시 번들 교체를 중단한다.
- 원본 보정은 공간 대조 및 사용자 확인 후 별도 이력으로 관리한다.
