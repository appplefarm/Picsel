# Picsel 픽셀 - 사진으로 떠나는 여행

**Picsel**은 대한민국의 아름다운 관광 사진을 탐색하고, 끌리는 장소를 목적지로 삼아 나만의 여행 지도를 채워나가는 **사진 기반 여행 목적지 추천 및 기록 앱**입니다.

<br/>

## ✨ 주요 기능 (Key Features)

### 1. 사진으로 고르기 🖼️

**"지역 정보 없이 관광사진을 둘러보고, 끌리는 사진을 눌러 목적지를 발견해요."**

- 텍스트나 지역 이름에 얽매이지 않고, 오직 눈길을 사로잡는 풍경 사진만으로 새로운 여행지를 탐색합니다.
- 마음에 드는 사진을 탭하여 해당 장소의 정보를 확인하고 최종 목적지로 설정할 수 있습니다.

### 2. 여행 떠나기 🚗

**"선택한 목적지와 경유지를 한눈에 확인하고, 순서와 이동 경로를 자유롭게 조정해요."**

- 목적지로 주변 관광지들을 추천받아 손쉽게 경유지로 추가합니다.
- 지도앱과 연동하여 완성된 최적의 경로를 한눈에 파악하고 수정할 수 있습니다.

### 3. 픽셀로 남기기 🧩

**"여행을 마치면 방문한 지역이 픽셀로 채워지고, 사진과 기록이 나의 픽셀맵에 쌓여요."**

- 대한민국 지도를 픽셀 형태로 시각화한 **'나의 픽셀맵'**을 제공합니다.
- 목적지에 방문하면 해당 시/군/구 단위의 지역이 초록색 픽셀로 칠해지며, 전국을 내 발자취로 채워나가는 성취감을 느낄 수 있습니다.

### 4. 픽셀 히스토리 📖

**"기록된 발자취를 언제든 다시 꺼내보며 추억해요."**

- 다녀온 여행들은 연도별로 정리되어 깔끔한 갤러리 형태로 기록됩니다.
- 각 여행에서 남긴 사진들과 방문 장소들을 쉽게 모아보고 관리할 수 있습니다.

## 🛠 기술 스택 (Tech Stack)

- **Platform:** iOS 17.0+
- **Framework:** SwiftUI
- **Architecture:** MVVM
- **Database:** SwiftData
- **Open API:** 한국관광공사 국문 관광정보 서비스 API, 한국관광공사 관광공모전(사진) 수상작 정보 API
