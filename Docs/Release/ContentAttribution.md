## 관광사진·관광 정보

- 제공처: 한국관광공사 / 한국관광콘텐츠랩 / TourAPI.
- 현재 출시 목록은 관광사진 정보에서 수집한 포항 19건이다. 전부 공모전 수상작 또는 공공누리 1유형이라고 단정하지 않는다.
- 원본 사진 ID·URL·제목은 `Resources/PhotoCatalog/pohang_photo_catalog.json`에 유지한다.
- [관광콘텐츠랩 이용약관](https://api.visitkorea.or.kr/#/agrAgreement) 제11조: 개별 콘텐츠 라이선스 준수·표시 및 한국관광공사 출처 표시. 사진을 기업 CI/BI 로고로 사용하지 않는다.
- [한국관광공사 저작권 보호정책](https://knto.or.kr/helpdeskCopyrightguide): 발행연도, 기관·URL, 표시된 저작자명을 함께 표시해야 한다. 공공누리 미표시 자료는 사전 협의 대상이며 제3자 권리도 별도로 확인한다.
- [관광사진 API](https://www.data.go.kr/data/15101914/openapi.do)의 이용권과 개별 이미지 이용권을 혼동하지 않는다. API에서 URL을 얻었다는 사실은 사진별 사용 허락 증빙이 아니다.
- JSON 및 기존 사진 정리 엑셀에는 작가·발행연도·사진별 라이선스 증빙이 없다. 촬영월을 발행연도로 대체하지 않는다.

### 앱 반영

- 설정의 데이터 및 콘텐츠 출처: 실제 제공처, 이용약관·저작권 정책 링크.
- 사진 탐색 및 상세: 한국관광공사 제공 표시와 출처 안내 진입점.
- 제공처 판별은 확인된 HTTPS 이미지 호스트에만 적용하며 사용자 사진에는 붙이지 않는다.
- 공용 PlaceDTO / Trip / RouteStop 모델과 카탈로그 응답 규격은 변경하지 않았다.

### 출시 전 남은 확인

- [ ] 19건을 원본 ID와 이미지까지 대조하여 원본 상세 페이지·작가·발행연도·라이선스·확인일 또는 별도 허락 증빙 확보.
- [ ] 해당 정보에 맞춰 **사진별** 작가·연도·라이선스 고지 추가. 현재 제공처 표시만으로 완료 처리하지 않는다.
- [ ] 비상업/변경금지 조건이 있다면 앱 배포 형태, 이미지 축소·캐시·크롭·프레임·RealityKit 공간 표현까지 허용 범위 확인. 확인 불가 건은 배포 대상 제외 또는 허락된 대체 사진 사용.
- [ ] 외부 URL 핫링크·이미지 캐시와 향후 서버 재배포 허용 범위 확인. 데이터 위치를 서버로 옮긴다고 권리 문제가 해결되는 것은 아니다.

## 지도 SDK

Package.resolved 기준: Google Maps 11.1.0 / NAVER NMapsMap 3.24.0 / NMapsGeometry 1.0.2.
SDK 소프트웨어 라이선스, 서비스 이용약관, 지도 데이터 고지는 각각 다르다.

### Google Maps

- [iOS SDK 출처 정책](https://developers.google.com/maps/documentation/ios-sdk/policies): SDK의 로고·제3자 데이터 표시를 숨기거나 가리지 않아야 한다.
- 홈 하단 그라데이션 제거, 위치 배지를 상단으로 이동. SDK 기본 로고를 직접 복제하거나 대체하지 않음.
- [SDK 개요의 고지 요구](https://developers.google.com/maps/documentation/ios-sdk/overview): 앱 안에서 `GMSServices.openSourceLicenseInfo()`의 원문 열람 메뉴 제공.
- 설정 → 데이터 및 콘텐츠 출처 → Google Maps SDK 오픈소스 라이선스에 연결. SDK를 갱신해도 해당 SDK가 제공하는 문자열을 그대로 표시.
- [서비스 이용약관](https://cloud.google.com/maps-platform/terms) 및 [서비스별 조건](https://cloud.google.com/maps-platform/terms/maps-service-terms)도 검토 대상.
- [ ] 실제 배포 화면에서 로고·저작권이 항상 보이고 탭 가능한지 작은 화면/가로/큰 글씨에서 확인.
- [ ] 별도 앱 이용약관·개인정보 처리방침의 지도 서비스 사용·외부 전송 고지, 계정의 결제/호출 제한과 실제 적용 계약 확인.

### NAVER Maps

- [iOS SDK UI 안내](https://navermaps.github.io/ios-map-sdk/guide-ko/4-1.html): NAVER 로고 노출 필수. 로고 탭이 꺼진 경우 별도 법적 공지·오픈소스 메뉴 필수.
- 로고 탭을 명시적으로 유지하고 모서리 여백 확보. 경로 계산 중 전체 지도 딤을 제거해 로고를 가리지 않음.
- 로고에서 법적 공지·오픈소스 라이선스에 진입하는 SDK 기본 흐름을 유지한다.
- [ ] 실제 경로 화면에서 로고 → 법적 공지/오픈소스 메뉴 동작 확인.
- [ ] 사용 중인 NAVER Cloud 계정의 Maps 서비스 계약, 호출량/요금, 경로 데이터 보관·전달 조건 확인.
